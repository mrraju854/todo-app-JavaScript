# 📝 To-Do App  

A simple and functional To-Do List application built using HTML, CSS, and JavaScript with localStorage support.

## ⚙️ Features  
- Add, delete, and manage tasks  
- Data saved using localStorage  
- Clean and responsive UI  
- Simple task management system  

## 🛠 Tech Stack  
HTML5, CSS3, JavaScript  

## 🌐 Live Demo  
https://project-3-todo.netlify.app/

## 🎯 Purpose  
Demonstrates CRUD operations, DOM manipulation, and localStorage usage in JavaScript.
